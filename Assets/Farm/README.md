# Уровень фермы

Основная сцена: `Assets/Scenes/FarmLevel.unity` — территория 64 × 48 тайлов.

В сцене находятся дом со стартовой точкой, сарай с пустым загоном, лавка семян,
небольшой хозяйственный сарай, шесть грядок, колодец, пруд с причалом,
небольшой сад, дорожки и лесная граница.
Персонажей, животных, врагов и игровых механик здесь пока нет.

## Редактирование

- `Farm Environment/Terrain`: четыре обычных Tilemap — основа, берег, дорожки,
  земля грядок. Базовый тайл 16 px; для стыков используются половинки по 8 px.
- `Buildings`: четыре здания собраны из отдельных деталей внутри SortingGroup.
  Сохранён родной размер пикселей: скаты, коньки и карнизы соединяются из
  соответствующих направленных модулей, окна и двери не растянуты.
- `Garden`, `Barnyard`, `Pond`, `Nature`: свободно перемещаемые SpriteRenderer.
- `Layout Markers`: невидимые точки старта, входов и будущих взаимодействий.
- `Collisions`: препятствия зданий, оград, деревьев, воды и границ карты.
- `Farm Camera`: обзор всей фермы. Для будущего игрока можно заменить её
  камерой слежения; персонажей следует сортировать по положению их ног.

Все изображения взяты из исходного `Assets/Tileset`. В `Farm/Atlases` находятся
точные копии PNG с отдельной нарезкой и настройками Point, 16 PPU, без сжатия.
Исходные изображения и их нарезка не изменены. Сцена не зависит от редакторского
генератора во время игры.

## Воспроизведение исходной планировки

`Tools/Farm/compose_buildings.py` создаёт описание и превью зданий из исходных
тайлсетов. `Tools/Farm/create_layout.py` создаёт `Design/farm-layout.json` и обзорный PNG.
Для запуска нужен Python с Pillow. Меню `Tools > Farm > Runner > Build Level`
собирает эту планировку в Unity. Повторная сборка заменяет содержимое FarmLevel,
поэтому перед ручными изменениями удобно сделать копию сцены. Несохранённая
сцена FarmLevel защищена от перезаписи.

`Tools > Farm > Runner > Capture Level` сохраняет снимки настоящей камеры в
`BuildArtifacts/FarmLevel-Unity.png`, `FarmLevel-Detail.png` и `FarmLevel-Barnyard.png`.
Проверка сцены и
результат последнего запуска записываются в `BuildArtifacts/farm-build-status.json`.
