# Порядок отрисовки фермы

Все перечисленные объекты используют Sorting Layer `Default`.

| Объекты | Order in Layer |
| --- | ---: |
| Земля и вода | 0 |
| Кромка берега | 5 |
| Дорожки | 10 |
| Почва грядок | 15 |
| Настил причала | 18 |
| Трава, клевер, цветы, мелкие камешки, камыши и кувшинки | 20 |
| Растения на грядках | 25 |
| Низкие предметы: брёвна, пни, небольшие камни, ящики, бочки, лавки | 30 |
| Игрок | 100 |
| Деревья, кусты, заборы, крупные камни, указатели, колодец и здания | От 200 |

Игрок больше не меняет Order при движении. Объекты ниже 100 всегда под ним,
объекты от 200 всегда поверх него.

У крупных объектов сохранён исходный взаимный порядок: прежние уникальные
номера заменены последовательными 200, 201, 202… Одинаковые исходные номера
остались одинаковыми. Поэтому деревья продолжают перекрывать друг друга
в прежнем порядке. Служебный компонент Farm Sorting Depth хранит исходный
порядок для повторного применения; во время игры он ничего не пересчитывает.

У здания из нескольких спрайтов общий порядок находится на Sorting Group.
Номера деталей внутри группы оставлены прежними: они определяют только
внутреннюю сборку здания и не сравниваются напрямую с номером игрока.

## Как применять к новым объектам

После добавления известных спрайтов запусти **Tools → Farm → Normalize Sorting Orders**.
Команда работает с FarmLevel, сохраняет резервную копию текущей сцены и применяет
правила ко всем экземплярам. Новый тип спрайта сначала нужно добавить в
`sorting-rules.json`; неизвестные спрайты вызывают понятную ошибку, а не получают
случайную категорию. Для нового дерева проще дублировать подходящее существующее
дерево. Если нужен другой взаимный порядок, настрой его явно перед первой нормализацией;
после первой нормализации исходный порядок хранится в служебном компоненте.

Единый список категорий находится в `sorting-rules.json`. Его используют и
Unity, и генератор `Tools/Farm/create_layout.py`. Пересборка карты и обновление
зданий также применяют эти правила. Полная пересборка карты по-прежнему заменяет
окружение: для изменения только порядка используй Normalize Sorting Orders.
